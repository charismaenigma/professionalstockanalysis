# MarketClarity production deployment

This directory is the Vercel production root for the MarketClarity Next.js application.

- Framework: Next.js
- Vercel root directory: `prodapp`
- Demo mode works without API keys.
- Live market data is enabled with `FMP_API_KEY`.
- Options are enabled with `MASSIVE_API_KEY`.
- Optional AI explanations are enabled with `OPENAI_API_KEY`.
