# MarketClarity demo

Beginner-friendly professional stock analysis demo for the PromptBase listing.

## Live demo

Once GitHub Pages is enabled for the `main` branch root, the demo will be available at:

https://charismaenigma.github.io/professionalstockanalysis/

## What this demo includes

- Four scoring models: Core Investment, Active Growth, Asymmetric Opportunity, and Swing Trade
- VTI and VOO comparison on every stock
- Beginner-first explanations with professional metrics preserved
- Example trade plan with entry, confirmation, invalidation, and targets
- Psychology/FOMO education
- Educational $100 allocation example
- Demo tickers: RSKD, KODK, SIMO

## Important

This public demo uses illustrative data only. It is not live market data and is not financial advice.
